# Getting help

| You want to… | Do this |
|---|---|
| Learn how to use the hub | Read the [user manual](docs/user-manual.md), or open **About → User guide and tours** on the hub for guided tours and step-by-step tutorials. |
| Report something that does not work | Open a [bug report](../../issues/new?template=bug.yml). |
| Correct a fact or a source | Open a [correction](../../issues/new?template=correction.yml). Please link the source you read. |
| Report an accessibility barrier | Open an [accessibility report](../../issues/new?template=accessibility.yml). |
| Suggest an idea or ask for a feature | Use the ideas box on the hub's **Help run the hub** page, or open an [idea](../../issues/new?template=idea.yml) or a [feature wish](../../issues/new?template=wishlist.yml). |
| Suggest an event for the calendar | Open an [event suggestion](../../issues/new?template=event.yml). |
| Suggest a source to add | Open a [source suggestion](../../issues/new?template=source.yml). |
| Report a security problem | Follow [SECURITY.md](SECURITY.md); do not open a public issue. |
| Volunteer | Read the [sustainability proposal](docs/sustainability-proposal.md) and use the expression-of-interest form on the hub's **Help run the hub** page. |

Issues are public. Do not include names of private individuals, contact details, health information or anything sensitive.

The hub is maintained in a personal capacity and by volunteers. Replies are best effort: new issues are looked at during the monthly triage. There is no telephone or email support.
