# Black & Mixed Heritage Portal

A vibrant portal celebrating Black and mixed cultures, history, heritage, and the African diaspora across the world.

## Overview

This project is a responsive single-page website designed to inform, inspire, and connect communities through storytelling, learning, and cultural celebration.

## Run locally

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Highlights

- Hero landing section with mission-driven messaging
- Interactive storytelling cards
- Heritage timeline and cultural highlights
- Community and event sections
- Educational resources and diaspora spotlight
- Accessible, mobile-friendly design
