# Architecture decision records

Short records of the decisions that shape the hub and this repository: the context, the decision and its consequences. A decision is changed by adding a new record that supersedes the old one, never by editing history.

| No. | Decision | Status |
|---|---|---|
| [0001](0001-single-self-contained-page.md) | The hub is one self-contained HTML page with no back end | Accepted |
| [0002](0002-github-pages-and-actions.md) | Host on GitHub Pages, deployed by GitHub Actions | Accepted |
| [0003](0003-ideas-through-github-issues.md) | Ideas and wishes go through GitHub issues, published as a read-only list | Accepted |
| [0004](0004-checks-in-the-page.md) | Quality checks run inside the page, and every check must be shown to fail | Accepted |
| [0005](0005-licences.md) | MIT for code, CC BY 4.0 for content | Accepted |
| [0006](0006-no-personal-data.md) | No personal data, analytics or tracking | Accepted |
| [0007](0007-supply-chain.md) | Pin actions by commit, least-privilege tokens, signed releases | Accepted |
| [0008](0008-wiki-from-docs.md) | The wiki is generated from `docs/wiki/`; Discussions start as announcements only | Accepted |
| [0009](0009-event-intake-through-pull-requests.md) | Community events reach the calendar through pull requests | Accepted |

Template: copy any record, give it the next number, and keep it to one page.
