# Reusing content and data

- **Text and data created for the hub:** Creative Commons Attribution 4.0. Credit "BHM 2026 Hub".
- **Code:** MIT.
- **Third-party material** keeps its own licence (for example the Open Government Licence v3.0); see [THIRD_PARTY_NOTICES.md](https://github.com/cyberdudeuk/black-mixed-heritage/blob/main/THIRD_PARTY_NOTICES.md).

Open data, on the website under `data/` and attached to each release:
| File | What |
|---|---|
| `bhm2026-events.ics` | The events calendar (iCalendar) |
| `bhm2026-events.json` | The same events as JSON |
| `bhm2026-glossary.csv` | Terms and definitions |
| `bhm2026-hub.jsonld` | The whole hub as linked data (Schema.org and SKOS) |

Field definitions: the [data dictionary](https://github.com/cyberdudeuk/black-mixed-heritage/blob/main/docs/data-dictionary.md). Verify a download with the release's `SHA256SUMS.txt`.
